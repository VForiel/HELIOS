# Mixed Layer Permutator Support

## Context
The user requested support for `PathPermutator` within parallel layers (e.g., `[None, PathPermutator, None]`). Previously, `PathPermutator` was only specially handled when it was a single layer (zero-width, direct arrows).

## Changes
Modified `src/helios/core/context.py`:
- Updated `_draw_layer_tree` to handle `PathPermutator` and `None` within the parallel layer loop.
- **None Handling**: Draws a dotted pass-through line instead of an icon.
- **PathPermutator Handling**:
    - Draws a dashed box boundary.
    - Draws internal crossed arrows to visualize permutation.
    - Skips standard icon drawing.
- **Connection Logic**: Updated to handle `None` and `PathPermutator` correctly (checking for `None` before accessing attributes).

## Validation
- Created `reproduce_mixed_permutator.py` to test `[None, PathPermutator([1,0]), None]`.
- Script executes successfully and generates `uml_mixed.png`.
- Visual inspection (inferred):
    - `None` slots should show pass-through lines.
    - `PathPermutator` slot should show crossed arrows.
    - Connections should route correctly to/from these elements.
