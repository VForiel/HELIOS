# Update get_input_wavefront parameters

## Changes
- Modified `Context.get_input_wavefront` in `src/helios/core/context.py` to accept optional `wavelength` and `size` arguments.
  - This allows users to override the simulation parameters defined in `Context.kwargs` when generating the initial wavefront.
- Updated `examples/09_end_to_end_simulation.py` to demonstrate passing simulation parameters to `Context`.
- Updated `tests.ipynb` (demo notebook) to use `Context` for managing simulation parameters and generating the initial wavefront via `ctx.get_input_wavefront()`.

## Rationale
- Provides more flexibility to the user to control wavefront generation parameters programmatically.
- Aligns the demo notebook with the recommended `Context`-based workflow.
