# Add Wavefront.plot() and Wavefront.copy()

## Summary
Added `plot()` and `copy()` methods to the `Wavefront` class in `src/helios/core/simulation.py`.

## Changes
- **`Wavefront.plot()`**: Visualizes amplitude and phase side-by-side using matplotlib.
- **`Wavefront.copy()`**: Creates a deep copy of the wavefront (including the field array), required for non-destructive processing in layers.
- **Imports**: Added `matplotlib.pyplot` and `copy`.

## Usage
```python
wf = helios.Wavefront(...)
wf.plot(title="My Wavefront")
wf_copy = wf.copy()
```
