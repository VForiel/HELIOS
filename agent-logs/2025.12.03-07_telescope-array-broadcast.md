# TelescopeArray Broadcast Mode

## Summary
Modified `TelescopeArray.process()` in `src/helios/components/collector.py` to always return a `WavefrontArray` (one wavefront per collector), even when the input is a single `Wavefront`.

## Changes
- **Broadcast Logic**: If a single `Wavefront` is provided, it is now copied N times (where N is the number of collectors).
- **Pupil Application**: Each collector applies its pupil mask to its corresponding wavefront copy.
- **Return Type**: Always returns `WavefrontArray`.

## Rationale
This unifies the interface for downstream components (like beam combiners) which expect N inputs corresponding to the N collectors, regardless of whether the upstream simulation used the optimized Atmosphere splitting or a simple Scene wavefront.

## Note
This change assumes that if a single wavefront is provided, it represents the field at each collector (ignoring geometric piston if not already encoded). For off-axis sources, the tilt is preserved, but the differential piston due to baseline separation is not automatically added by this broadcast (unless the input wavefront was already "global" and we are just sampling it, but here we are copying it). This is consistent with the user request for "equivalent to receiving a WavefrontArray with always the same WaveFront".
