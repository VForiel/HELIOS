# Decomposition of Demo Notebook into Scripts

## Summary
Decomposed the `demo.ipynb` notebook into 11 numbered Python scripts in the `examples/` directory. Each script corresponds to a logical section of the notebook and is self-contained (imports necessary modules and sets up required objects).

## Created Scripts
1.  **`examples/01_scene_observation.py`**: Scene setup, object addition, and SED visualization.
2.  **`examples/02_telescope_pupil.py`**: Manual and preset pupil construction, PSF visualization.
3.  **`examples/03_interferometry.py`**: VLTI and LIFE interferometer configuration and baseline visualization.
4.  **`examples/04_atmospheric_turbulence.py`**: Static atmospheric phase screens and frozen-flow evolution.
5.  **`examples/05_atmospheric_animation.py`**: Animations of turbulence over single telescopes and interferometers.
6.  **`examples/06_coronagraphy.py`**: Vortex and 4-Quadrant coronagraphs, starlight suppression, and planet detection.
7.  **`examples/07_chromatic_psf.py`**: Analysis of chromatic PSF degradation due to atmosphere.
8.  **`examples/08_end_to_end_simulation.py`**: Full simulation pipeline (Scene -> Collectors -> Camera).
9.  **`examples/09_uml_visualization.py`**: Automatic UML diagram generation for optical pipelines.
10. **`examples/10_photonic_circuit.py`**: Simulation of a simple photonic integrated circuit.
11. **`examples/11_photonics_uml_generation.py`**: Complex UML diagram generation for a photonic beam combiner (from `generate_photonics_uml.py`).

## Verification
- All scripts include `sys.path.insert` to correctly locate the `helios` package.
- Scripts are numbered to suggest a logical execution order.
- Each script wraps its logic in a `run_demo()` function and uses `if __name__ == "__main__":` block.
