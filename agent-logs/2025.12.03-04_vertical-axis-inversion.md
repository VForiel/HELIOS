# Vertical Axis Inversion for UML Diagrams

## Context
The user requested that elements with lower indices (e.g., index 0) should appear *above* elements with higher indices in the UML diagram. Previously, index 0 was at the bottom (lowest Y).

## Changes
Modified `src/helios/core/context.py`:
- **`_calculate_branch_positions`**:
    - Inverted the generation of Y positions.
    - Formula changed from `start_y + i * spacing` to `start_y + (num_branches - 1 - i) * spacing`.
    - This ensures that `i=0` gets the maximum Y value (Top) and `i=N` gets the minimum Y value (Bottom).
