# Wavefront Plot Label Improvements

## Summary of Changes
- Modified `Context.get_input_wavefront` in `src/helios/core/context.py`:
    - Now stores source coordinates as `astropy.Quantity` (radians) instead of raw tuples when generating extended source grid.
    - This enables downstream formatting to know the physical unit.
- Modified `src/helios/core/simulation.py`:
    - Added `_format_coord` helper function.
        - Converts coordinates to the most appropriate unit (`uas`, `mas`, `arcsec`, `arcmin`, `deg`) to display as integers (or close to integers) between 0 and 999.
        - Defaults to `mas` for (0,0).
    - Updated `Wavefront.plot` and `WavefrontArray.plot` to use `_format_coord` for labeling sources.

## Files Modified
- `src/helios/core/context.py`
- `src/helios/core/simulation.py`

## Tests
- Created and ran `tests/test_label_formatting.py` (deleted after verification):
    - Verified `_format_coord` logic for various inputs (0, small angles, large angles).
    - Verified `Context.get_input_wavefront` returns Quantities.
    - Confirmed that labels are formatted as requested (e.g., "206, 206 mas" for 1e-6 rad).
