# WavefrontArray plot unit-aware axes

## Summary of changes
- Enhanced `WavefrontArray.plot()` in `src/helios/core/simulation.py` to support unit-aware axes and labeled colorbars, consistent with `Wavefront.plot()`.
- Dynamic figure sizing based on channel count.
- Computes `extent` from `pixel_scale` when provided as `astropy.units.Quantity`, selecting readable units (mm/m for length, arcsec/deg for angles).
- Labels axes with units and colorbar as Amplitude.

## Files modified
- `src/helios/core/simulation.py`

## New functions/classes
- None (method updated).

## Tests/validation
- Visual validation expected in `tests.ipynb` where `WavefrontArray.plot()` is used in interferometer and propagation sections. Axes should display unit labels when `pixel_scale` is set.

## Notes
- Method focuses on amplitude per channel for clarity. If phase visualization is desired, we can add a 2-row grid similar to the previous implementation.
