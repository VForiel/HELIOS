# Wavefront Plotting Log Scale

## Summary of changes
- Added `log_scale` parameter (default `False`) to `Wavefront.plot()` and `WavefrontArray.plot()`.
- When `log_scale=True`:
    - `Wavefront.plot()` displays 3 subplots: Amplitude, Log Amplitude, Phase.
    - `WavefrontArray.plot()` displays 3 rows: Amplitude, Log Amplitude, Phase.
- Log amplitude is calculated as `log10(abs(field) + 1e-12)` to handle zeros.
- Colorbars and axes units are consistent across all plots.

- `src/helios/core/simulation.py`

## New functions/classes
- None (methods updated).

## Tests/validation
- Created and ran `tools/test_plot_log.py` to verify execution of log scale plotting for both single wavefronts and arrays.
- Visual verification in notebooks will show the additional log amplitude plots when `log_scale=True` is passed.
