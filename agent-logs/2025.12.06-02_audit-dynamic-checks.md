# Audit Dynamic Checks & Refactoring

## Context
Continuing the audit of the codebase to remove dynamic `hasattr`/`getattr` checks and enforce strict attribute usage via `__slots__` and `astropy.Quantity`.

## Changes

### `src/helios/core/simulation.py`
- **Fixed npix default handling**: Changed default from `npix=256` to `npix=None` to properly detect when `size=int` should set npix.
- **Replaced hasattr checks**: Center coordinates now use `u.Quantity(x, u.m).to(u.m).value` instead of `hasattr(x, 'to')`.

### `src/helios/components/atmosphere.py`
- **Replaced all hasattr checks with u.Quantity conversions**:
  - `rms`: `u.Quantity(rms, u.m)`
  - `wind_speed`: `u.Quantity(wind_speed, u.m/u.s)` for both scalar and tuple inputs
  - `inner_scale`, `outer_scale`: `u.Quantity(x, u.m)`
  - `time`: `u.Quantity(time, u.s)`
  - `wavelength`: `u.Quantity(wl, u.m)`
  - `ref_size`: `u.Quantity(size, u.m)`
  - Zernike coefficients: `u.Quantity(coeff, u.rad)`

### `src/helios/components/collector.py`
- **Added null check for source_directions**: Fixed `TypeError` when `wf.source_directions is None`.
- **Replaced hasattr checks**: Direction coordinates now use `u.Quantity(dirs[s][i], u.rad)`.
