# Collector Pixel Scale Update

## Summary of changes
- Modified `Collector.process()` in `src/helios/components/collector.py` to automatically update the wavefront's `pixel_scale`.
- The new `pixel_scale` is calculated as `collector_size / number_of_pixels`.
- This ensures that after passing through a collector (telescope), the wavefront physically represents the field at that aperture size (e.g., an 8m telescope produces an 8m wide wavefront grid).

## Files modified
- `src/helios/components/collector.py`

## New functions/classes
- None (method updated).

## Tests/validation
- Created and ran `tools/test_collector_scale.py`.
- Verified that a wavefront passing through an 8m collector correctly updates its pixel scale to `0.08 m` (for a 100px grid).
