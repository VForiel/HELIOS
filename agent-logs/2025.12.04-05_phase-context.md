# Moving Phase Tilt to Context

## Summary of Changes
- Modified `Context.get_input_wavefront` in `src/helios/core/context.py`:
    - Added calculation of geometric phase tilt for off-axis sources.
    - Uses `diameter` from `kwargs` (default 10m) to define the wavefront spatial grid.
    - Applies tilt $\phi_{tilt} = k(u\theta_x + v\theta_y)$ to the generated wavefront field.
- Modified `TelescopeArray.process` in `src/helios/components/collector.py`:
    - Removed the tilt calculation loop.
    - Retained the piston calculation $\phi_{piston} = k(c_x\theta_x + c_y\theta_y)$ to account for the collector's position in the array.
    - This separation of concerns ensures that the input wavefront represents the field incident on the array (with tilt), and the collector samples it at a specific location (adding piston).

## Files Modified
- `src/helios/core/context.py`
- `src/helios/components/collector.py`

## Tests

    - Verified that `TelescopeArray.process` correctly adds the piston phase shift corresponding to the collector's position.
