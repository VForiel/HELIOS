# Lens Optical Element Added

Date: 2025-12-03

## Summary
Added a new `Lens` element to apply paraxial thin-lens quadratic phase in the pupil plane. Supports both `Wavefront` and `WavefrontArray` inputs.

## Files
- `src/helios/components/lens.py` (new): Lens implementation with unit-aware API, documentation, and a basic test function.
- `src/helios/components/__init__.py`: Export `Lens` from components.
- `src/helios/__init__.py`: Expose `Lens` at package level and add to `__all__`.

## API
- `helios.Lens(focal_length: u.Quantity, center: Tuple[u.Quantity, u.Quantity] = (0*u.m, 0*u.m))`
- Method: `process(wavefront, context)` applies phase to `Wavefront` or each channel in a `WavefrontArray`.

## Tests
- `test_lens_basic()` in `lens.py`: Validates phase application and output shape.

## Notes
- Uses `wavefront.pixel_scale` for coordinate mapping; defaults to `1 m/pixel` if unspecified.
- Downstream propagation (FFT to focal plane) is handled by detector/camera or dedicated propagation layers.
