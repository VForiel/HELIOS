# Add WavefrontArray Class

## Summary
Added `WavefrontArray` class to `src/helios/core/simulation.py` to manage collections of wavefronts on parallel optical paths.

## Features
- **Container**: Holds a list of `Wavefront` objects.
- **List-like interface**: Supports indexing `[]`, iteration, `len()`, and `append()`.
- **`copy()`**: Deep copies all contained wavefronts.
- **`plot()`**: Visualizes all wavefronts in a grid (Amplitude/Phase rows × N columns).

## Usage
```python
wfs = helios.WavefrontArray([wf1, wf2])
wfs.plot(title="Parallel Beams")
```
