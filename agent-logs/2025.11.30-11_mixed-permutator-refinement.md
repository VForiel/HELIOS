# Mixed Layer Permutator Refinement

## Context
The user requested a refinement of the `PathPermutator` visualization logic:
1.  **Single Layer**: If `PathPermutator` is the only element (single layer), it should be drawn as direct connections (zero-width).
2.  **Mixed/Parallel Layer**: If `PathPermutator` is part of a parallel layer, it should be drawn as a standard block, but indicating the permutation mapping.

## Changes
Modified `src/helios/core/context.py`:
- **`_draw_layer_tree`**:
    - Reverted the custom "dashed box" drawing for `PathPermutator` inside the parallel loop.
    - Now calls `_draw_layer_icon` for `PathPermutator` in parallel mode, treating it as a standard block.
- **`_draw_layer_icon`**:
    - Added `PathPermutator` to `icon_map` (using `mmi.svg` as icon).
- **`_get_display_name`**:
    - Added special handling for `PathPermutator` to display `Perm: [mapping]` as the label.

## Validation
- Ran `reproduce_mixed_permutator.py`.
- Expected output:
    - The mixed layer `[None, Perm, None]` should show a block for the Permutator.
    - The block should be labeled `Perm: [1, 0]`.
    - Connections should converge to/from the block.
- Single layer behavior (not tested in this script but code is untouched) should remain as direct arrows.
