# Frontend UI Reorganization

## Summary
Reorganized the frontend component sidebar and node visualization to group elements by Layer Type.

## Changes
- **`web/frontend/src/App.jsx`**:
    - Grouped sidebar components into 4 categories:
        - **Generation**: Scene Source (Blue)
        - **Sampling**: Telescope, Atmosphere (Cyan)
        - **Optical**: Lens, Beam Splitter, Coronagraph, Fiber Input/Output, Photonic Chip (Indigo)
        - **Detection**: Camera (Pink)
    - Updated headers and spacing in the sidebar.

- **`web/frontend/src/components/flow/nodes/LayerNode.jsx`**:
    - Added `getLayerStyle` function to dynamically determine node colors based on contained elements.
    - Applied dynamic background, text, and border colors to the node header and container.
    - Colors match the sidebar categories:
        - Scene -> Blue
        - Telescope/Atmosphere -> Cyan
        - Camera -> Pink
        - Others -> Indigo

## Verification
- Sidebar should now show 4 distinct sections with colored headers.
- Dragging a component onto the canvas should create a node (or add to existing) that reflects the layer type color in its header icon and hover border.
