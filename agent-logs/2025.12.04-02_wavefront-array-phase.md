# WavefrontArray Plot and Phase Shift Update

## Summary of Changes
- Modified `WavefrontArray.plot` in `src/helios/core/simulation.py`:
    - Refactored plotting loop to iterate over sources (samples) first, then channels (wavefronts).
    - Updated layout to match `Wavefront.plot` logic: Amplitude, Phase, (Log Amp) side-by-side for each (Source, Channel) pair.
    - Ensures consistent visualization of multi-channel, multi-source simulations.
- Modified `TelescopeArray.process` in `src/helios/components/collector.py`:
    - Added geometric phase shift calculation for off-axis sources.
    - Uses `source_directions` from input `Wavefront` to apply phase shift $\phi = \vec{k} \cdot \vec{r}_{collector}$ where $\vec{k}$ depends on source direction.
    - This corrects the phase for planets/stars not on the optical axis when using distributed collectors.

## Files Modified
- `src/helios/core/simulation.py`
- `src/helios/components/collector.py`

## Tests
- Added `tests/test_wavefront_array_phase.py`:
    - Verifies `WavefrontArray.plot` calls `plt.subplots` with correct dimensions (Sources * Channels rows).
    - Verifies `TelescopeArray.process` applies correct phase shift to off-axis sources based on collector position.
    - Confirmed phase shift is $\pi/2$ for a specific test case ($x=100m, \theta=2.5 \text{ nrad}, \lambda=1\mu m$).
