## PHYSIQUE EXPLIQUÉE

### Contexte : Gaines Monomodes à Saut d'Indice

Une gaine monomode (single-mode waveguide) à saut d'indice est une structure 
optique simple:
  • Cœur de largeur W avec indice n_eff
  • Gaine (air) avec indice n_clad ≈ 1.0
  • Mode fondamental LP₀₁ confiné par réflexion interne totale

### Paramètres Ajoutés

**Sin (Input Mode Width):**
- Largeur du mode fondamental de la gaine d'ENTRÉE
- Unité: mètres
- Défaut: (W / N) / 4 (comportement original)
- Interprétation: Largeur 1/e² de l'intensité du mode LP₀₁

**Sout (Output Mode Width):**
- Largeur du mode fondamental de la gaine de SORTIE
- Unité: mètres  
- Défaut: Sin (ou (W / N) / 4 si Sin=None)
- Interprétation: Largeur effective de couplage en sortie

### Principes Physiques Appliqués

#### 1. PROFIL MODAL (Mode Fondamental)
Chaque gaine monomode contient un mode fondamental approximativement gaussien:

    ψ(x) = [1/√(∫|ψ|²dx)] × exp(-(x - x_center)² / (S/2)²)

Où S est la largeur effective (Field Mode Width, FMW) du mode.

**Implémentation:** Nouvelle fonction `_compute_mode_profile(x_grid, center, width)`
- Crée un profil gaussien centré à "center" avec largeur "width"
- Normalise pour que ∫|ψ|² dx = 1
- Utilisée pour les entrées (Sin) et sorties (Sout)

#### 2. COUPLAGE EN ENTRÉE
Le champ à l'entrée du MMI est construit en superposant les modes d'entrée:

    E_input(x) = Σᵢ amplitudeᵢ × ψ_i(x)

où ψ_i(x) est le profil du mode d'entrée centré au port i avec largeur Sin.

**Effet:** Sin détermine comment la lumière s'injecte dans le MMI
- Sin petit → couplage étroit, haute directivité
- Sin grand → couplage large, propagation plus douce

#### 3. COUPLAGE EN SORTIE (OVERLAP INTEGRAL)
L'intensité à chaque sortie est calculée par:

    P_j = |∫₀ᴾ E(x,L) · ψ_j(x) dx|²

où:
- E(x,L) = champ complexe à la sortie du MMI (z=L)
- ψ_j(x) = mode fondamental normalisé du port de sortie j
- Sout définit la largeur de ψ_j

**Interprétation Physique:**
- L'intégrale de recouvrement (overlap) mesure comment bien le champ du MMI 
  s'accouple avec le mode de la gaine de sortie
- P_j = 1 : 100% du flux est couplé au port j
- P_j = 0 : Aucun flux n'est couplé (orthogonal au mode)

**Effet physique:** Plus Sout est large, plus d'énergie est capturée
- Sout=1 µm → Détection sélective (peu de lumière capturée)
- Sout=5 µm → Détection large (beaucoup de lumière capturée)

## IMPLÉMENTATION DÉTAILLÉE

### Fonction Nouvelle: `_compute_mode_profile()`

```python
def _compute_mode_profile(x_grid, center, width):
    """
    Crée le profil du mode fondamental d'une gaine monomode.
    
    Paramètres:
    -----------
    x_grid : np.ndarray
        Grille spatiale transverse [m]
    center : float
        Position du centre du mode [m]
    width : float
        Largeur effective (FMW) du mode = rayon 1/e² [m]
    
    Retour:
    -------
    np.ndarray
        Profil normalisé ψ(x) tel que ∫|ψ|² dx = 1
        Units: [1/√m]
    """
```

**Physique implémentée:**
- Profil gaussien: exp(-(x-center)² / (width/2)²)
- Normalisation énergétique: ∫|ψ|² dx = 1
- Intégration numérique avec la grille fournie

### Modifications aux Fonctions Principales

#### `simulate(N, M, L, W, ..., Sin=None, Sout=None)`
- **Avant:** Utilisait beam_waist = (W/N)/4 partout
- **Après:** 
  - Sin contrôle l'injection (entrée)
  - Sout contrôle la détection (sortie)
  - Calcul d'intensité: I_j = |∫ E(x,L) · ψ_j(x) dx|²

#### `compute_contributions(N, M, ..., Sin=None, Sout=None)`
- Passe Sin/Sout à _compute_mmi_field() et aux calculs de phasors
- Les "phasors" sont les coefficients de couplage complexes de chaque entrée 
  vers chaque sortie

#### `calibrate_input_phases_genetic(..., Sin=None, Sout=None)`
- Optimise les phases d'entrée en tenant compte de Sin/Sout
- Cherche les phases qui maximisent la sortie "bright" en minimisant les sorties "null"

## ÉTAPES PHYSIQUES APPLIQUÉES

### Étape 1: Construction du Mode d'Entrée
```
Pour chaque port d'entrée i:
  1. Créer profil gaussien de largeur Sin centré au port i
  2. Normaliser ce profil
  3. Multiplier par l'amplitude d'entrée
  4. Superposer tous les ports pour obtenir E_input
```

### Étape 2: Propagation dans le MMI (Mode Expansion)
```
1. Décomposer E_input en modes propres du MMI dur l'axe z:
   E(z,x) = Σₘ cₘ(z) φₘ(x)
   
   où φₘ sont les modes hard-wall (sinus)
   
2. Propager chaque mode avec son propre nombre d'onde βₘ:
   cₘ(z) = Cₘ⁰ × exp(-i×βₘ×z)
   
3. Reconstruire le champ: E(z,x) = Σₘ cₘ(z) φₘ(x)
```

### Étape 3: Couplage en Sortie
```
Pour chaque port de sortie j:
  1. Créer profil gaussien de largeur Sout centré au port j
  2. Normaliser ce profil
  3. Calculer l'intégrale de recouvrement:
     A_j = ∫₀ᵂ E(L,x) × conj(ψ_j(x)) dx
  4. Intensité du port j: I_j = |A_j|²
```

### Étape 4: Résultats
```
• Amplitudes complexes en sortie: [A_1, A_2, ..., A_M]
• Intensités en sortie: [|A_1|², |A_2|², ..., |A_M|²]
• Contraste de nullage: min(I) / max(I)
• Pureté modale: quelle fraction se couple dans chaque mode
```

## CONSEILS PRATIQUES

### Choisir Sin et Sout

**Pour la photonique intégrée (Silicon Photonics):**
- Longueur d'onde λ = 1.55 µm
- Gaine monomode typique: noyau ≈ 300-500 nm
- FMW mode ≈ 2 × noyau ≈ 1-2 µm
- **Recommandé:** Sin = Sout = 1.5 µm

**Pour la fibre optique:**
- Longueur d'onde λ = 1.55 µm
- Noyau monomode ≈ 4-5 µm
- FMW mode ≈ 5-8 µm
- **Recommandé:** Sin = Sout = 6 µm

**Pour les tests sans données réelles:**
- Commencer avec Sin = Sout = (W/4) ≈ 2.5 µm pour W=10 µm
- Variant Sout seul pour étudier l'effet du couplage de détection
- Sin et Sout peuvent être différents pour asymétrie intentionnelle

### Interprétation des Résultats

**Si vous observez:**
- Intensités très petites → Champ se couple mal aux modes de sortie
  - Causes: Sin/Sout trop petits ou mal positionnés
  - Solution: Augmenter Sin/Sout progressivement

- Intensités saturées (proches de 1) → Couplage très efficace
  - Bon signe si les modes sont bien alignés
  - Peut indiquer Sin/Sout trop grand

- Asymétrie entre sorties → Comportement normal
  - Dépend de la propagation interne et du couplage modal
