# Multimode Interferometers (MMIs)

This mini-guide explains the physics of Multimode Interference (MMI) couplers and how HELIOS implements them numerically for design, simulation, and calibration. It is concise but complete: key formulas are given with physical interpretation, and the corresponding numerical choices used in the code are made explicit.

If you are new to MMIs, start with Physical Principles, then skim Design Rules, and finally see Numerical Implementation to connect the physics to HELIOS internals.
