# MMI Simulation Tools

Low-level simulation tools for Multi-Mode Interferometers (MMI).

These functions provide direct access to the Eigenmode Expansion (EME) solver used to model MMI behavior. They are useful for parameter scans, design optimization, and generating educational visualizations.
